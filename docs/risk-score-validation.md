# 风险计分规则 · 历史数据验证

> 数据源：`customer_risk_his`（1000 条历史画像）。用完整 8 维规则重算总分 → 按风险等级分数区间归级 → 核对各档实际理赔率是否落在题目要求的分位区间。逐行明细见 [`risk-scores-1000.csv`](risk-scores-1000.csv)。

## 一、计分公式（8 维）

```
总分 = BMI + 血压 + 吸烟 + 饮酒 + 个人病史 + 年龄 + 职业 + 家族病史
```

各维取值口径与 `risk-rules.json` 一致：

| 维度 | 取值 → 加分 |
|------|-----------|
| BMI | <18.5→10；18.5~25→0；25~28→5；28~32→15；≥32→30 |
| 血压 | 正常/正常高值→0；临界高血压→5；轻度高血压→15；中度高血压→30 |
| 吸烟 | 不吸烟→0；已戒烟→5；吸烟→15 |
| 饮酒 | 不饮酒·偶尔→0；经常→20 |
| 个人病史 | 轻度异常→5/10（累加）；中度→25/30/45 |
| 年龄 | <18→0；18~40→0；41~50→10；51~60→20；60+→40 |
| 职业 | 低风险→0；中风险→5；高风险→15 |
| 家族病史 | 低风险→0；中风险→5；高风险→15 |

## 二、风险等级分数区间

| 风险总分范围 | 风险等级 | 目标理赔概率 |
|------------|---------|------------|
| 0 ~ 45 | 标准体 | <47.5% |
| 46 ~ 69 | 次标体 A 级 | [47.5%, 67.5%) |
| 70 ~ 84 | 次标体 B 级 | [67.5%, 82.5%) |
| 85 ~ 99 | 高风险体 | [82.5%, 97.5%) |
| ≥100 或本人病史命中拒保疾病 | 拒保体 | — |

> 拒保疾病（本人病史）：恶性肿瘤（癌症）、严重器官疾病（心衰/肾衰/肝硬化）、严重精神疾病、AIDS/HIV、药物/酒精成瘾、近 6 个月内曾有拒保记录 —— 直接判定拒保体，不累计计分。

## 三、验证结果（1000 条，四档全部满足）

| 风险等级 | 分数范围 | 人数 | 理赔数 | 实际理赔率 | 目标区间 | 是否满足 |
|---------|---------|-----:|-----:|---------:|---------|:------:|
| 标准体 | 0 ~ 45 | 407 | 125 | 30.7% | <47.5% | ✅ |
| 次标体 A 级 | 46 ~ 69 | 298 | 171 | 57.4% | [47.5%, 67.5%) | ✅ |
| 次标体 B 级 | 70 ~ 84 | 171 | 126 | 73.7% | [67.5%, 82.5%) | ✅ |
| 高风险体 | 85 ~ 99 | 82 | 69 | 84.1% | [82.5%, 97.5%) | ✅ |
| 拒保体 | ≥100 或直接拒保 | 42 | 42 | 100.0% | — | — |

**结论**：8 维计分规则 + 上述分数区间自洽——四个评分档的真实理赔率均精准落在题目要求的分位区间内。

## 四、附：关于 score_v1

历史画像表的 `score_v1`（第一版风险评分）经反推验证 = **6 维**（BMI + 血压 + 吸烟 + 饮酒 + 个人病史 + 年龄），**不含职业和家族病史**（这两维对 score_v1 贡献恒为 0）。CSV 中同时保留 `score_v1(旧六维)` 与本次重算的 `八维总分` 以便对照。
